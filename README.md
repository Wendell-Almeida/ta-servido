# 🍽️ Tá Servido?

O **Tá Servido?** é uma plataforma web desenvolvida como Trabalho de Conclusão de Curso (TCC) com o objetivo de preservar e valorizar a cultura gastronômica brasileira por meio do compartilhamento de receitas tradicionais e regionais.

Inspirado em plataformas como TudoGostoso, o projeto permite que qualquer pessoa publique, descubra e favorite receitas, promovendo a preservação do patrimônio cultural gastronômico e incentivando a participação da comunidade.

## ✨ Funcionalidades

* 👤 Cadastro e autenticação de usuários
* 🍲 Publicação e edição de receitas
* 📸 Upload de imagens
* 🔍 Pesquisa de receitas
* ❤️ Sistema de favoritos
* ⭐ Avaliações e comentários
* 👥 Perfis de usuários
* 📱 Interface responsiva
* ☁️ Armazenamento em nuvem com Firebase

## 🛠️ Tecnologias

### Front-end

* Angular
* TypeScript
* Tailwind CSS
* PrimeNG

### Back-end e serviços

* Firebase Authentication
* Cloud Firestore
* Firebase Storage

## 🎯 Objetivo

O principal objetivo do Tá Servido? é contribuir para a preservação da identidade cultural brasileira por meio da culinária, oferecendo um espaço onde receitas tradicionais possam ser registradas, compartilhadas e descobertas por novas gerações.
